# 仓库查询工具数据仓库

这个仓库只放库存位置数据。

核心文件：

```text
inventory.json
```

后续新增货号、修改货架位置、添加未上架/走廊尽头货号，只需要替换这个文件。

如果使用 GitHub Pages，请在仓库 Settings → Pages 中设置：

```text
Source: Deploy from a branch
Branch: main
Folder: / root
```

启用成功后，数据地址应类似：

```text
https://baihui-sudo.github.io/warehouse-query-data/inventory.json
```
